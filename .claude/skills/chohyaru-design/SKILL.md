# 초하루 디자인 시스템

매달 첫날, 지난달에 내가 쓴 일기로 만든 편지가 도착하는 일기 앱.
주 사용자는 **기록은 하지만 돌아보지는 않는 20대**.

룩의 정체성 한 줄: **미색 종이 바탕 + 명조체 편지 + 아주 절제된 흙빛 포인트.**
화면이 아니라 **종이**처럼 보여야 한다. 앱스러운 요소(그림자, 카드, 알림 배지, 컬러 아이콘)가 늘어나는 순간 이 룩은 깨진다.

핵심 정서: **조용함.** 이 앱은 사용자를 부르지 않는다. 사용자가 열었을 때만 말한다.

## 1. 디자인 토큰 (확정 — 값 그대로 사용, 임의 색 추가 금지)

```css
/* 라이트 — 낮의 종이 */
:root{
  --bg:#FAF8F5;      /* 배경 — 미색 종이. #FFFFFF 순백 금지 */
  --text:#2B2723;    /* 본문 — 먹색. #000000 완전 검정 금지 */
  --sub:#9A9188;     /* 날짜·캡션·보조 문구 */
  --accent:#8B7355;  /* 인용 링크·버튼·점 — 여기서만 */
  --line:#E8E2DA;    /* 구분선 */
  --ph:#C7C0B7;      /* placeholder */
  --mark:#F0E7DA;    /* 일기 상세의 인용 문장 하이라이트 */
  --hover:#F2EDE6;   /* 캘린더 날짜 hover */
  --envbody:#FFFFFF; --envflap:#F6F2EC;  /* 봉투 */
}

/* 다크 — 밤의 종이 */
[data-theme="dark"]{
  --bg:#1C1A18;      /* 어두운 갈빛. #000000 순검정 금지 */
  --text:#E8E1D6;    /* 미색 글자. #FFFFFF 순백 금지 */
  --sub:#948B80;
  --accent:#C4A67D;  /* 어두운 배경에선 흙빛을 밝게 올린다 */
  --line:#332F2B;
  --ph:#5C564F;
  --mark:#3A342C;
  --hover:#252220;
  --envbody:#211F1C; --envflap:#262320;
}
```

**색은 모드당 다섯 개가 전부다.** 상태색(빨강/초록/노랑) 없음. 감정별 색 없음.

`--accent`는 화면당 두세 군데까지. 인용 링크, 저장 버튼, 캘린더 점, 봉투 봉인 정도.
넓은 면을 accent로 채우면 종이 느낌이 즉시 사라진다.

## 2. 타이포그래피

```css
--serif: 'Gowun Batang', serif;   /* 편지·일기 본문 전용 */
--sans:  -apple-system, 'Apple SD Gothic Neo', 'Malgun Gothic', sans-serif;  /* UI */
```

이 앱의 정체성은 **명조와 고딕의 역할 분리**에 있다.

| 명조(serif) | 고딕(sans) |
|---|---|
| 편지 본문 | 날짜 헤더 |
| 일기 본문·입력창 | 버튼 라벨 |
| 앱 이름, 월 표시 | 캡션, 안내 문구 |

- 편지·일기 본문: 15.5~16px · **행간 2.0~2.05** · 문단 간격 22px
- 행간이 이 룩의 절반이다. 1.7 이하로 좁히면 편지가 아니라 문서가 된다
- 굵기는 400만. **bold 금지** — 강조가 필요하면 색(`--accent`)이나 여백으로
- UI 텍스트: 13~15px · weight 400~500

## 3. 다크모드

### 원칙

밤에 읽는 종이는 검정이 아니라 **어두운 갈빛**이다. 색을 단순히 반전시키면 종이가 아니라 터미널이 된다.

1. **순검정·순백 금지** — 배경 `#1C1A18`, 글자 `#E8E1D6`. 대비를 최대로 올리면 눈이 아프고 종이 느낌이 사라진다
2. **accent는 밝게 올린다** — 어두운 배경에서 `#8B7355`는 묻힌다. `#C4A67D`로 교체
3. **글자 굵기는 그대로 400** — 다크모드에서 얇아 보인다고 굵히지 말 것. 명조는 얇아야 한다
4. **테마 전환 애니메이션 금지** — 즉시 전환. 페이드는 앱스러워진다
5. **전환 스위치 위치**: 설정이 아니라 잠금 화면 하단에 조용히. 이 앱에 설정 화면은 없다

6. **하드코딩된 색이 하나라도 남으면 안 된다** — placeholder, 하이라이트, hover, 봉투까지 전부 토큰으로. 라이트에서 잘 보이던 `#F0E7DA` 같은 값이 다크에선 형광 얼룩이 된다

### ⚠️ 실제로 겪은 버그: 색 상속 함정

테마 변수를 특정 컨테이너(`.phone`, `.app` 등)에만 걸면, **그 바깥에서 이미 계산된 글자색이 그대로 상속되어** 배경만 어두워지고 글자는 검은 채로 남는다. CSS 변수는 참조가 아니라 계산된 값으로 상속되기 때문이다.

```css
/* 테마 컨테이너와 각 화면에 색을 다시 선언할 것 */
.phone{ background:var(--bg); color:var(--text); }
.screen{ background:var(--bg); color:var(--text); }
```

명조체 본문·제목처럼 눈에 띄는 요소에는 `color:var(--text)`를 **명시적으로** 지정한다. 상속에 기대지 말 것.

두 모드 모두에서 편지 화면을 눈으로 확인할 것. 명조체는 다크모드에서 인상이 크게 달라진다.

## 4. 여백 규칙

- 화면 좌우 패딩 **26px** (좁으면 답답, 넓으면 허전)
- 화면 상단 여백 **52px** — 상태바 아래 충분히 비운다
- 허전해 보이는 것이 정상이다. 빈 공간을 채우려는 충동을 참을 것

## 5. 시그니처 화면: 편지

이 앱에서 사람들이 스크린샷 찍을 유일한 화면. 여기에만 공을 들인다.

**구조**: 월 표시(sub, 가운데) → 편지 본문(명조, 문단 이어짐) → 서명(우측 정렬, sub)

**본문 안 인용 링크**
```css
.lk{color:var(--accent); border-bottom:1px solid rgba(139,115,85,.4); cursor:pointer;}
```
누르면 그날 일기로 이동. 밑줄은 **흐리게** — 문장 읽는 흐름을 끊으면 안 된다.

**절대 하지 말 것**
- 인용문을 큰 글씨로 가운데 띄우기 (전시하는 느낌 → 편지가 아니게 됨)
- "12일엔", "24일엔" 식으로 날짜 붙이기
- 퍼센트 게이지, 통계 카드, 분석 요약 블록
- 편지 아래 버튼 여러 개 (여운이 끊긴다)

## 6. 캘린더 — 가장 위험한 화면

잘못 만들면 빈 칸이 죄책감의 격자가 된다. 이 앱이 비판하는 대상이 되어버린다.

| ✅ 이렇게 | ❌ 이러면 안 됨 |
|---|---|
| 쓴 날 아래 4px 점 하나 (`--accent`) | 안 쓴 날에 X·빗금·회색 채움 |
| 점은 단색 | 감정별 컬러 히트맵 |
| 안 쓴 날은 아무 표시 없음 | "3일 연속" 배지 |
| 매달 1일만 `--accent` 글자색 | "20/31일 (66%)" 채움률 |
| 상단 문구 "12일의 기록" | "달성률 39%" |

- 안 쓴 날을 눌러도 그 날짜 일기를 쓸 수 있다. **"놓쳤다"가 아니라 "아직 안 썼다"**
- 안 쓴 날에도 점 자리만큼 높이를 비워둘 것 (칸 높이가 들쭉날쭉하면 안 됨)

## 7. 컴포넌트 규격

- **버튼**: 알약형(radius 20px), 높이 38~40px, `--accent` 테두리 1px. 채움 버튼은 화면당 1개
- **입력창**: 테두리·배경 없음. 배경에 그냥 명조체 글자가 놓인 것처럼. placeholder는 `--ph`
- **아이콘**: 선 아이콘만, stroke 1.4px, `--sub` 색, 22px. **이모지 금지** (종이 톤이 깨짐)
- **봉투**: `--envbody` 사각형 + `--envflap` 삼각 플랩 + `--accent` 원형 봉인. 그림자 없음
- **구분선**: 1px `--line`. 최후의 수단으로만 — 여백이 먼저다
- **카드**: 쓰지 않는다. 이 앱에 카드 UI는 없다
- **스크롤바**: 숨긴다 (`scrollbar-width:none` + `::-webkit-scrollbar{display:none}`). 편지 옆 스크롤바는 종이 느낌을 깬다

## 8. 편지 문안 톤 (카피 작성 시 필수)

편지의 화자는 AI가 아니라 **지난달의 나**다.

**형식**: 인사로 시작 → 회상 → 다음 달의 나에게 한마디 → 서명("7월의 나로부터")

| 이렇게 | 이러면 안 됨 |
|---|---|
| 주어 생략 | "당신은", "○○님은" |
| "~했더라", "~했네", "~였어" | "~하셨습니다", "~하셨군요" |
| "나는 그날이 제일 좋았어" | "잘 버텼습니다", "대단해요" |
| 문단이 앞 문장을 받아 이어짐 | 한 줄씩 툭툭 끊김 |
| "언제 괜찮아졌는지 모르겠어" | "아홉 번 썼다" (집계 어투) |

**가장 흔한 실패는 요약 보고다.** "N번 썼다", "그 얘기가 없다" 같은 문장만 이어지면 반말로 쓴 월간 리포트가 된다. 편지는 세지 않는다. 회상하고, 감상을 붙이고, 한마디 남긴다.

**함정**: 반말이 자기비판으로 읽히지 않게. "왜 이것밖에 못 했냐" ❌ / "그래도 안 놨네" ✅
말투는 편하게, 태도는 다정하게. **나를 아끼는 내가** 쓰는 편지다.

**좋은 날을 반드시 섞을 것.** 편지가 고생담 모음이 되면 컨셉이 무너진다. 날씨 좋았던 날, 웃겼던 날, 별거 없던 날을 함께 인용한다.

## 9. UI 마이크로카피

- 담백한 반말 또는 짧은 명사형. 앱이 말을 많이 걸지 않는다
- 잠금 화면: "매달 첫날, 편지가 옵니다"
- 캘린더: "7월, 12일의 기록"
- 봉투: "7월의 편지가 도착했습니다"
- 빈 화면에 "아직 기록이 없어요 ✏️" 같은 독려 금지. 그냥 비워둔다

## 10. 하지 말 것

- 팔레트 외 색 추가, 그라데이션, 그림자, 글로우 금지
- 다크모드에서 순검정 배경·순백 글자 금지 (§3)
- 이모지, 컬러 아이콘, 일러스트 금지
- 스트릭·달성률·연속 기록·레벨·배지 등 게이미피케이션 **일체 금지**
- 감정 그래프, 통계 대시보드, 워드클라우드 금지
- 푸시 알림으로 기록 독려 금지 (편지 도착 알림만 허용)
- 편지 공유·SNS 내보내기 금지 (공유가 붙으면 일기가 검열된다)
- bold 남용, 12px 미만 텍스트, 행간 1.7 이하 금지
- 외부 UI 라이브러리(부트스트랩, MUI 등) 금지 — 위 토큰으로 직접 스타일링
